# 版本紀錄 (Changelog)

本專案採用 [語意化版本](https://semver.org/lang/zh-TW/) (Semantic Versioning)：
`主版本.次版本.修訂版本`，例如 `0.1.0`。

- **修訂版本 (patch, 0.1.x)**：修 bug、調整文字，不改變資料庫結構、不影響既有功能。
- **次版本 (minor, 0.x.0)**：新增功能，但保持向下相容 (舊資料、舊 API 呼叫方式仍可用)。
- **主版本 (major, x.0.0)**：有不相容的重大改動 (例如砍掉某個 API、改變資料庫結構且無法自動遷移)。

每次要發新版本時，請照下面順序做：

1. 確認 `migrations/` 資料夾內，這次有改資料表結構的話，是否已經新增一支新的
   `00X_描述.sql` (數字比目前最大的編號 +1)。**不要修改已經發布過的舊 migration 檔案**，
   永遠用新增檔案的方式描述改動，這樣舊使用者的資料庫升級時才能正確地「補跑」新的異動。
2. 更新 `package.json` 的 `version` 欄位。
3. 在下面新增一個版本區塊，寫清楚這個版本改了什麼。
4. 佈署新版程式碼、重啟服務 (`npm start`)。伺服器啟動時會自動偵測並套用尚未執行過的
   migration，不需要手動操作資料庫。
5. 佈署後，用 `/api/health` 確認版本號正確、用 `/api/debug` (見 README「除錯」章節)
   確認資料庫migration 都已套用、外部資料源連線正常。

## [0.4.0] - 2026-07-23

股票深度大改版 + 機票深連結修正 + 全站 UI 視覺優化：

- 股票 (參考 Yahoo 股市資訊密度大幅擴充)：
  - 新增台股加權指數 (TAIEX) 大盤卡片：`/api/stocks/index/taiex` (證交所官方 FMTQIK)。
  - 新增個股估值資料：本益比/殖利率/股價淨值比 `/api/stocks/valuation/:code`
    (證交所官方 BWIBBU_ALL)。
  - 個股卡片新增「開盤/最高/最低/成交量/振幅」數據格與漲跌幅百分比。
  - 新增近 40 個交易日「收盤走勢 + MA5 + MA20 均線」互動圖 `/api/stocks/history/:code`。
  - 三大法人買賣超拆解為「外資/投信/自營商」分項 (最新交易日 + 近15日累計)，
    資料自證交所 T86 動態欄位解析。
- 機票/訂房深連結修正 (回報「點過去跳錯誤」)：
  - 實測確認長榮 `/zh-tw/booking/` 已 404，改連官網首頁。
  - Skyscanner 改用正確的 `/transport/flights/{IATA}/{IATA}/{yymmdd}/` 格式，
    新增 60+ 常用城市中文名→IATA 機場代碼對照表；查不到代碼時誠實降級。
  - 每個連結標示「已帶入條件」或「需自行輸入」徽章，不再假裝所有連結都能預填
    (航空公司官網刻意不開放帶參數訂票網址，需商業合作 API)。
- UI 全面優化：新版設計系統 (漸層品牌色、卡片陰影、hover 效果、聊天氣泡、
  provider 清單頭像、kv 數據格、hero 首頁、深色模式配色重整)；台股慣例
  漲=紅/跌=綠；首頁快捷卡涵蓋全部六個模組。

## [0.3.0] - 2026-07-23

交通、股票、AI 助理三大方向的大幅擴充，回應「深連結訂票」「車次時間篩選+收藏」
「股票要更詳細」「加一個能聊天的 AI 助理」等需求：

- 交通／機票／訂房：
  - 新增「深連結」服務 (`src/services/deeplinks.js`)：輸入出發地/目的地/日期(或城市/入住退房)，
    直接產生 Google 航班、Skyscanner、長榮/華航/虎航、Booking.com/Agoda/Trip.com/AsiaYo
    等各家網站的預填搜尋連結，點下去就帶好查詢條件。明確告知這不是真正比價 API。
  - 台鐵/高鐵時刻查詢新增 `to`(目的站)、`date`、`timeFrom`/`timeTo`(時間範圍)、`trainNo`
    (車次搜尋) 篩選參數，回傳每筆車次含到達時間與票價(估)。
  - 新增「收藏車次」功能 (`favorite_trains` 資料表 + `/api/travel/train/favorites` CRUD)。
  - 智慧行程規劃新增 `CURATED_SPOTS` 精選推薦清單 (`src/services/itinerary.js`)：目前收錄
    「台中」「新北」兩城市，整理自公開旅遊/美食部落格的景點/美食/休閒建議 (質化描述，
    非即時 Google 評分，因未串接 Google Places API 金鑰)。
- 股票：
  - 新增均線描述性指標 `/api/stocks/indicator/:code` (MA5 vs MA20，僅描述近期相對位置，
    非價格預測 — 刻意不做「未來走勢預測」功能，原因詳見 `src/services/twse.js` 註解)。
  - 新增費城半導體指數 (SOX) `/api/stocks/index/sox`：使用 Yahoo Finance 非官方端點，
    已明確標示 `isUnofficialSource`。
  - 新增相關新聞 `/api/stocks/news/:code`：串接 Yahoo奇摩股市官方 RSS。
- 新增行事曆 (`calendar_events` 資料表 + `/api/calendar` CRUD)：可依日期/時間新增行程。
- 新增 AI 助理聊天 (`/api/assistant/chat`)：伺服器端呼叫 Anthropic Claude API (需於 `.env`
  設定 `ANTHROPIC_API_KEY`)，涵蓋日常聊天/生活規劃/股票解讀/翻譯等主題，未設定金鑰時
  會提供清楚的「尚未設定」提示訊息而不是報錯。
- 新增資料庫 migration：`002_favorites_and_prefs.sql`、`003_calendar.sql`。
- 展示預覽版 (單檔 HTML) 同步更新，前端以模擬假資料呈現以上所有新功能，方便不架伺服器
  也能體驗完整介面與互動。

## [0.1.0] - 2026-07-23

初版原型，包含：

- 帳號系統 (註冊/登入/登出)，App 與網站共用同一組帳號與資料庫，個人化模組顯示設定。
- 股票：串接證交所公開資料 (每日收盤 + 三大法人買賣超)，含規則式參考訊號 (非投資建議)。
- 交通：串接交通部 TDX 平台查詢台鐵/高鐵時刻與動態 (需自行申請免費金鑰，否則使用示範資料)。
- 機票+住宿比價：目前為示範資料，架構已預留正式 API 串接位置。
- 智慧行程規劃：規則式行程草案產生器。
- 日記：依日期記錄，支援從本機文字檔匯入。
- 記帳：手動輸入收支、分類統計圖表、月度趨勢圖、預算設定。
- 系統：零外部 npm 依賴 (只用 Node.js 內建模組)、SQLite 資料庫 + 自動 migration、
  結構化 log 與 `/api/debug` 除錯端點、`/api/health` 健康檢查。
